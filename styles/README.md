# الستايلات الجاهزة (Style presets)

كل مجلد = اتجاه فني كامل: `style.json` (قيم الستايل المتوافقة مع `pipeline/style.py`) و`STYLE.md` (دليل: الجوهر وما ليس هو، المواد والرسم،
الإيقاع والإخراج، تعليمات للمخرج البصري). يُختار من القائمة «ستايل جاهز…» في الواجهة أو `POST /api/style {"preset": "<slug>"}`،
ويُمرَّر الدليل إلى المخرج البصري وإلى كاتب المشاهد (`AUTHORED_SCENES=1`).

| المجلد | الاسم | يناسب |
|---|---|---|
| `atlas` | أطلس قديم | جغرافيا، تاريخ الأماكن، لماذا نُقلت العاصمة |
| `chalkboard` | سبورة المعلّم | تصحيح خطأ شائع، أصل اسم، درس بفكرة واحدة |
| `dossier` | ملف التحقيق | ألغاز، «لماذا فشل؟»، «من قرر ولماذا؟» |

## إضافة ستايل
انسخ مجلداً، عدّل `style.json` (نفس مفاتيح الستايل؛ القيم الخارجة عن المسموح تُستبدل)، واكتب `STYLE.md` بالأقسام الأربعة نفسها.
اختبار `tests/test_presets.py` يتحقق من القيم والأقسام.

## المصدر والترخيص
