٣. المخرج البصري — مشهد حركي لكل جملة

عند نطق كل جملة يظهر مشهد خاص بها مرسوم بالكود في Remotion: خريطة، رقم، مقارنة، خط زمني، قائمة، أيقونات، أو كانفس حر بعناصر وأسهم. DeepSeek يصمّمها من نص الجملة، وبلا مفتاح تُبنى مقاطع بسيطة آمنة. يمكنك تعديل JSON أي مقطع في بطاقات السكربت أعلاه.

٣-ب. مكتبة العناصر البصرية والرسوم المتحركة (Visual Elements Library)

أيقونات Iconify محلية (Lucide / Phosphor / Tabler)، إيموجي SVG مدمجة، أعلام الدول، رسوم Lottie، مخططات D3 المتحركة، ومكوّنات التيبوغرافيا — تعمل 100% دون إنترنت وقت الرندر.
